# Between Us (Kola & Joy) 🏡✨

A cozy, intimate virtual hangout space for long-distance couples—not a chat app, but a place they go to just to be together.

## Features
- **The Room**: Layered attic loft with dual live skies (Manchester & Houston), two brass time zone clocks, avatars on the sofa & beanbag, and ambient table lamp.
- **The Arcade**: Turn-based Ludo, Chess, Connect Four, 36 Questions, Would You Rather, Rose Bud Thorn, and live Doodling Canvas.
- **Mailbox**: Origami love letters, voice notes with waveform player, postcards, and sealed time capsules.
- **Together**: Reunion countdown with mini walking couple timeline and shared date-planning calendar.
- **Memories**: Pinned polaroids, game win archives, and shared milestones.

## 📦 How to Build & Download the APK on GitHub

The repository is configured with automated **GitHub Actions** (`.github/workflows/build-apk.yml`).

### Steps to Get the APK:

1. **Push your code to GitHub** (or connect this project via the AI Studio GitHub export/settings).
2. On your GitHub repository page:
   - Click on the **Actions** tab at the top.
   - Select the workflow named **Build Between Us APK** from the left sidebar.
   - Click the **Run workflow** button (or it will automatically run on every push).
3. Once the build finishes (takes about 2–3 minutes):
   - Click on the completed workflow run.
   - Scroll down to the **Artifacts** section at the bottom of the page.
   - Click on **BetweenUs-Android-APK** to download the ZIP file containing `BetweenUs-debug.apk`.
4. Transfer or open the `.apk` file on your Android phone (and send a copy to Joy) to install and start hanging out!
