# Between Us (Kola & Joy) 🏡✨

A cozy, intimate virtual hangout space for long-distance couples—not a chat app, but a place they go to just to be together.

## Features
- **The Room**: Layered attic loft with dual live skies (Manchester & Houston), two brass time zone clocks, avatars on the sofa & beanbag, and ambient table lamp.
- **The Arcade**: Turn-based Ludo, Chess, Connect Four, 36 Questions, Would You Rather, Rose Bud Thorn, and live Doodling Canvas.
- **Mailbox**: Letters, voice notes with waveform player, postcards, and sealed time capsules.
- **Together**: Reunion countdown with mini walking couple timeline and shared date-planning calendar.
- **Memories**: Pinned polaroids, game win archives, and shared milestones.

## 🚀 Releases & APK Downloads

Every time code is pushed or the GitHub Action runs, a new release is automatically created under your repository's **Releases** tab!

### Versioning Rules
- Starts at `v1.1` and increments `.1` with each build:
  - `v1.1`, `v1.2`, ... `v1.9`, `v1.10`
- Once it reaches `.10`, it advances to the next major version:
  - `v2.1`, `v2.2`, ... `v2.10` -> `v3.1`!

### Where to Download:
1. Go to your repository on GitHub.
2. Click on **Releases** on the right sidebar (or navigate to `https://github.com/<owner>/<repo>/releases`).
3. Under the latest release (e.g. `v1.1`), under **Assets**, tap **`BetweenUs-v1.1.apk`** (or `BetweenUs-latest.apk`) directly from your Android phone browser to install!
